# WireGuard Real Server Panel

این نسخه علاوه بر مدیریت کاربران، تلاش می‌کند WireGuard واقعی را داخل محیط اجرا نصب/راه‌اندازی کند.

## الزامات پلتفرم
کانتینر باید دسترسی `NET_ADMIN`، `/dev/net/tun` و امکان ساخت interface شبکه داشته باشد. برای Docker/Compose از `privileged: true` یا حداقل capability مناسب استفاده کنید. اگر پلتفرم ابری این دسترسی‌ها را مسدود کند، هیچ پنل داخل کانتینری نمی‌تواند از داخل همان کانتینر یک VPN واقعی روی شبکه میزبان بسازد؛ در آن حالت باید WireGuard روی VPS/Host نصب شود یا پلتفرم دسترسی شبکه را ارائه کند.

## راه‌اندازی
1. `WG_ENDPOINT` را روی IP یا دامنه واقعی سرور بگذارید.
2. رمز ادمین و SECRET_KEY را عوض کنید.
3. پورت UDP 51820 را در فایروال باز کنید.
4. کانتینر را با Compose اجرا کنید.
5. وارد پنل شوید و «نصب/راه‌اندازی خودکار WireGuard» را بزنید.
6. کاربر بسازید؛ peer به صورت خودکار در `wg0` اعمال می‌شود.

## امکانات
- ساخت/حذف/فعال/غیرفعال‌کردن Peer واقعی
- تولید کلید WireGuard با `wg genkey/wg pubkey`
- تولید فایل `.conf`
- تولید QR
- آدرس‌دهی خودکار از subnet
- ساخت کانفیگ سرور و اعمال با `wg-quick`
- ذخیره پایدار تنظیمات و کاربران در `/data`

## محدودیت مهم
Quota حجمی، قطع خودکار بر اساس مصرف و آمار دقیق RX/TX در این نسخه UI ساده نیست؛ برای این موارد باید حسابداری ترافیک (nftables/iptables + job زمان‌بندی‌شده) اضافه شود. همچنین اگر Stackdome دسترسی NET_ADMIN/TUN را ندهد، اجرای WireGuard واقعی از داخل کانتینر ممکن نیست.
